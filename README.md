# Создание highload в realtime-среде

## Требования

1. Обслуживание пользователей из всех регионов РФ (все часовые пояса).
2. Компания хочет сделать упор на развитие в регионах РФ.
3. Бесперебойная работа сервиса 24/7.
4. RTO — 45 мин.
5. RPO — 15 мин.
6. Доступность ≥ 99,9%.
7. Одинаковое время загрузки страниц для пользователей из разных регионов.
8. Ожидается существенный прирост пользователей.
9. Размер данных ≥ 50Gb. 

## Проблемы
1. Сайт медленно загружает страницы (запросы поиска — 50 RPS, запросы оформления — 10 RPS).
2. Нарушается SLA для B2B-клиентов (250 RPS).
3. Приложение падает.
4. Команда узнает о падениях от пользователей.
5. Восстановление занимает часы.
